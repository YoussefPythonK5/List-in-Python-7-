# List-in-Python-7-

This program is a simple practical exercise in Python to demonstrate how to handle and manage lists. It focuses on how to store data and update it dynamically.

🛠️ Tools Used
Programming Language: Python 3.x.
Data Structures: Lists (used for storing the collection of fruits).
Methods: append() (used to add new elements to the end of the list).

🚀 How It Works
Initialization: The program starts with a predefined list containing three fruits.
Modification: It uses the append() method to insert a new item ("mango") at the very end of the list.
Output: It prints the state of the list before and after the modification to verify the update.

💻 How to Run
Ensure you have Python installed on your system.
Download the script file (e.g., script.py).
Open your terminal or command prompt.
Run the script using the command: python script.py.
